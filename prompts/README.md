# 添削プロンプトについて

| ファイル | 内容 | 公開 |
|---|---|---|
| `es_review_lite.md` | 簡易版。基本の観点のみ。このリポジトリに同梱 | 公開 |
| `es_review.md` | 正式版。種類別の詳細チェック観点・面接深掘り観点・評価の錨を持つ | 非公開（有償） |

アプリは起動時に `es_review.md` があればそれを、無ければ `es_review_lite.md` を読み込みます。
どちらを使っているかは画面左「準備の確認」の「添削プロンプト」に表示されます。

正式版は、X版・LINE版キャリアボットで運用しているES添削プロンプトと同じマスターです。
提供については https://careerbot.tokyo からお問い合わせください。

`es_review.md` は `.gitignore` に含めているため、このフォルダで `git push` しても公開されません。
